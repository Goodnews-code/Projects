## 🛠️ Technical Overview

Most projects in this collection prioritize **clean, vanilla web technologies** to ensure high performance and accessibility:

- **Frontend**: HTML5, CSS3, JavaScript (ES6+).
- **Layout**: CSS Grid, Flexbox, Media Queries for responsiveness.
- **Assets**: Optimized images and standard web fonts (Inter, Poppins, Jost).

## 🚀 How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Goodnews-code/Projects.git
   ```
2. **Navigate to an individual project folder**:
   ```bash
   cd Projects/Trueminds
   ```
3. **Open the entry point**:
   - Simply open `index.html` in any modern web browser.
   - Alternatively, use the **Live Server** extension in VS Code for a local development experience.
